# 🧮 Calculadora – Projeto de Extensão Codificadoras 🐈💜

Este repositório contém o código de uma **calculadora desenvolvida em Python com Tkinter**, criada como parte do **projeto de extensão Codificadoras**.

---

## 🌱 Objetivo

Ensinar, durante as oficinas do projeto Codificadoras:

- Lógica de programação  
- Fundamentos da linguagem **Python**  
- Conceitos básicos de **interfaces gráficas (GUI)** usando a bibliteca Tkinter do Python 
- Raciocínio lógico aplicado à resolução de problemas

---

## ⚙️ Como funciona

A calculadora possui uma interface gráfica desenvolvida com a biblioteca **Tkinter**, permitindo que o usuário interaja com botões numéricos e operações matemáticas.

### Funcionalidades implementadas:
- Operações básicas:  
  - ➕ Soma  
  - ➖ Subtração  
  - ✖️ Multiplicação  
  - ➗ Divisão  

- Operações matemáticas adicionais:  
  - √ Raiz quadrada  
  - ∛ Raiz cúbica  
  - Exponenciação  

- Operações trigonométricas:  
  - sen(x)  
  - cos(x)  
  - tan(x)  

- Funcionalidades extras:
  - Botão **DEL** para apagar o último dígito  
  - Botão **RESET** para limpar toda a operação  
  - Botão **ON/OFF**, que desativa a calculadora e exibe uma mensagem no visor para avisar o usuário que a calculadora está desligada
  - Suporte a números decimais, utilizando o botão da vírgula na calculadora
 
---

## 🖥️ Tecnologias utilizadas

- **Python 3**
- **Tkinter** (interface gráfica)
- Biblioteca `math` para cálculos matemáticos
- Organização visual baseada em `Frame`, `Label` e `Button`
